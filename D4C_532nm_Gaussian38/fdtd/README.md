# Finite Gaussian FDTD experiment

All files and solver products here belong to the new `AH53_D4C_ZeroOrder_20261105` experiment. Existing projects remain read-only. `run_fdtd.py` checks the ASCII junction `D:/AH53_D4C_zero_native_20261105` resolves to this same project before saving any native file. It launches its own hidden Lumerical v252 CAD session, one CPU engine with eight threads, and restores its own resource properties when closing.

The actual source is a normal-incidence 2D scalar Gaussian beam, Ez polarization, amplitude 1 V/m, waist radius 19 um at y=0. This uses the user-confirmed 38 um intensity 1/e^2 diameter convention. The source is at y=1.35 um; the source fit band is 500–600 nm, and every exported field is evaluated at 532 nm. Actual `getfdtdindex` values are in `materials.json`, shared with the matched RCWA calculation.

The original eight structures have nine16 um periods and300 nm relief. AH53 has three1.6 um wide Si ridges per period, centered at local x=-3.2,0,+3.2 um. Binary50 has one8 um wide ridge per period. Cap000 means bare Si/air. For positive cap values, SiO2 fills the grooves to y=300 nm and covers the ridges by the stated100/150/200 nm cap. Si ridges override the lower-priority oxide rectangle. The planar film extends laterally over the substrate and into the PML. A later independent weak-scan holdout is defined in`inputs/extra_weak_mark.json`: AH53 relief180 nm and planar cap400 nm, top580 nm. This changes both relief and film; it is not a film-only comparison. The original eight geometry records remain unchanged and the holdout never enters their parameter calibration.

The initial calibration uses an explicitly uniform dx=20 nm/dy=10 nm grid and32 PML layers. Flat-Si reflection is3.05% below matched Fresnel, so the production grid is instead dx=10 nm/dy=5 nm over the entire domain with64 PML layers. Its flat-Si reflection is0.7264% below Fresnel; this residual is retained, with no Fresnel correction. Both meshes have the same physical Y-PML thickness320 nm and X-PML thickness640 nm. The x span is192 um, y=[-0.8,2.5] um, and all four actual boundaries are PML. The Gaussian tails are negligible at the x boundaries. The line monitors span184 um at R=1.8 um, R2=2.0 um, INC=0.8 um, T=-0.6 um. The common optical reference is y=0.85 um. All six raw E/H components are saved as NPZ. No background subtraction or per-structure renormalization is applied during export. Native Poynting flux and source power, engine actual time and shutoff, actual boundaries, grid, source and geometry are separately recorded.

`audit_fields.py` performs a separate E/H directional decomposition and flux calculation. Its fixed air reference gives common incident power. Flat-Si/Fresnel comparison tests numerical interface accuracy; full-monitor spatial flux versus angular flux tests normalization independently. The air solve quantifies source backward leakage. R/R2 checks the effect of propagation between independent monitors. These audits precede optical-model comparisons, since a scalar zero-order transfer cannot remove Maxwell discretization error.

Only case folders with a valid `DONE.json` establish successful actual solves. `settings.json` is the requested model, `observed_settings.json` the saved solver properties, and `engine_result.json` the native process outcome. - `ah53_cap150_fine_t200` independently tests the thin-film case at200 fs. Time validity is not silently inferred for every material solely from the bare-Si case.

The script checks source, domain, mesh, PML and completed reference shutoff before reusing it. These are not counted as additional air solves.
