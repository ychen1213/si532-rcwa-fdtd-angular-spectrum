## message-0030 · 助手 · 正式回答 · 2026-10-31T12:07:49+08:00

<!-- MESSAGE_BODY_BEGIN:message-0030 -->
你的理解有道理：**在理想的 50% 占空比二值振幅光栅或二值相位光栅模型中，非零偶数阶确实为零。** 我上一份报告只用一句话说“几何占空比不保证偶数电磁衍射级为零”，没有把这个区别解释清楚。

这次算的是有实际厚度的 **Si 表面浮雕光栅的完整电磁散射**。它的几何轮廓虽然是 50% 占空比，但实际反射电场并不严格满足理想二值光栅所要求的场分布，所以二级可以有有限值。

先看你熟悉的结论从哪里来。设一个周期内的几何函数为

\[
g(x)=
\begin{cases}
1,&0\le x<\Lambda/2,\\
0,&\Lambda/2\le x<\Lambda.
\end{cases}
\]

它的第 \(m\) 个傅里叶系数为

\[
g_m=\frac{1-(-1)^m}{i2\pi m},\qquad m\ne0.
\]

所以 \(m=\pm2,\pm4,\ldots\) 时，**几何函数的偶数阶系数严格为零**。

如果进一步假设：在同一个参考平面上，反射复场在凸台区域是一个常数 \(E_a\)，在沟槽区域是另一个常数 \(E_b\)，那么

\[
E_r(x)=E_b+(E_a-E_b)g(x).
\]

此时反射场本身也是一个 50% 占空比的二值函数，其非零偶数阶自然全部为零。这就是理想薄光栅或局域二值响应模型中的结论；相位差和两个常数的大小可以改变衍射效率，但不会改变这个零点。这个结论也对应标准的 [50% 占空比方波振幅光栅分析](https://www.spiedigitallibrary.org/journals/optical-engineering/volume-58/issue-08/087105/Understanding-diffraction-grating-behavior--including-conical-diffraction-and-Rayleigh/10.1117/1.OE.58.8.087105.full)。

实际 Si 浮雕结构多了一步：**需要先由 Maxwell 方程求出真实的反射场，然后才能对这个场做傅里叶分解。** 在凸台、沟槽和侧壁附近，电磁场会发生横向耦合和散射；反射场通常不是“凸台上一个常数、沟槽上另一个常数”。本例的 Si 折射率约为 \(4.15+0.048i\)，空气与 Si 的介电对比很大，台阶深度为 100 nm，因此不能仅凭几何方波就断定实际反射场也是理想方波。

从 RCWA 的耦合关系可以更具体地看出原因。把介电函数和电场分别展开：

\[
\varepsilon(x)=\sum_j\varepsilon_j e^{ijGx},
\qquad
E(x)=\sum_n E_n e^{inGx},
\qquad G=\frac{2\pi}{\Lambda}.
\]

Maxwell 方程中的乘积 \(\varepsilon E\) 的二阶分量为

\[
[\varepsilon E]_2=\sum_n\varepsilon_{2-n}E_n.
\]

50% 占空比使几何调制的 \(\varepsilon_2=0\)，因此 **从零级直接耦合到二级的那一项** \(\varepsilon_2E_0\) 为零；但还可以有

\[
0\ \longrightarrow\ 1\ \longrightarrow\ 2
\]

这样的间接耦合，对应式中的 \(\varepsilon_1E_1\) 等项。这些项不受 \(\varepsilon_2=0\) 的直接限制，合起来就可能产生有限的二级场。这里的“多次散射”仍然属于**线性光学**，不是说 Si 出现了非线性光学效应。RCWA 对这些空间谐波进行耦合求解，而不是只取一次几何轮廓的傅里叶变换。[RCWA 原始方法文献](https://opg.optica.org/josaa/abstract.cfm?uri=josaa-12-5-1068)

另一个容易混淆的是对称性：本例结构关于中心轴**镜像对称**，所以正负级在统一原点下相等，即 \(r_{+m}=r_{-m}\)。但把结构平移半个周期会把凸台与沟槽互换，这不是同一个 Si–空气结构的对称操作，因此镜像对称本身并不要求偶数级为零。

本次保存的数据也支持二级是真实模型中的有限响应，而不是单纯由 FDTD 的有限窗口旁瓣造成：

| 结果 | \(+2\) 级复振幅 | 每个二级的反射效率 |
|---|---:|---:|
| 周期结构 RCWA | \(0.063222+0.013902i\) | 约 \(0.3548\%\) |
| 50 周期细网格 FDTD 提取 | \(0.060756+0.012678i\) | 约 \(0.3262\%\)，由中心复振幅估计 |

这里的效率相对**入射功率**，而不是相对总反射功率。RCWA 的最后两组收敛计算从 161 增加到 321 个谐波时，所有传播级中最大的复振幅变化约为 \(1.46\times10^{-5}\)，远小于二级振幅的模 \(0.0647\)。这表明二级不能简单解释成 RCWA 谐波截断误差；FDTD 与 RCWA 之间仍有报告中列出的有限长度和网格误差。

因此，对这个问题最准确的说法是：**50% 占空比保证理想二值几何函数的非零偶数傅里叶系数为零；若实际出射或反射场也能近似成对应的二值函数，偶数衍射级才随之为零。** 完整电磁计算中偶数级既不被保证为零，也不意味着一定非零；本次 Si 浮雕参数下，计算得到的二级是有限的。

**是的，你现在说的这个理解是对的。** 对于足够长的有限周期结构，FDTD 中某一级附近的一整个角谱分布，可以对应 RCWA 中的一个离散衍射级。要比较这一整束光的影响，**积分是完全合理的**。

我之前回答“取中心值，不需要积分”说得不够完整。更准确地说：

- 取中心值并正确归一化，是一种提取 RCWA 复系数的方法。
- 对该级附近的**复角谱积分**，经过正确归一化，也可以得到接近 RCWA 的复系数。
- 对该级附近的**功率谱积分**，可以得到这一整束光的功率，再与 RCWA 的该级衍射效率比较。

这三种做法比较的是相关但不同的量。下面用我们已经算出的结果具体说明。

对于无限周期 RCWA，第 \(m\) 级出现在一个确定的横向波数

\[
q_m=\frac{2\pi m}{\Lambda}
\]

上，复振幅系数是 \(r_m\)。严格地说，它在连续角谱中对应的是一个带权重的 **Dirac δ 峰**；\(r_m\) 对应这个峰的权重，而不是普通曲线上某个有限高度的点。

有限长度 \(L=N\Lambda\) 会把这个 δ 峰展宽。如果暂时只看一个衍射级，理想矩形窗口下，在统一的参考面上，它的角谱近似为

\[
A_m(q)=L E_i r_m\,
\operatorname{sinc}\!\left[\frac{(q-q_m)L}{2}\right].
\]

随着 \(L\) 增大，这个峰**变窄、变高**。因此，一个越来越窄的 FDTD 角谱范围，可以在极限意义上趋近 RCWA 的一个离散级。这正是你直觉里“一个点对应一个范围”的数学表达。

下面这张图就是之前实际计算得到的对比：蓝线是真实 400 周期 FDTD 角谱；橙线是把 RCWA 的离散级用同样长度的有限窗口展开后得到的分布。图中纵轴画的是归一化**复场的模**。

可以看到，RCWA 的一个级经过同样的有限窗口处理后，也会对应一整束主瓣和旁瓣。有限阵列与无限周期结构使用不同远场表示的问题，Ansys 的[有限周期阵列远场说明](https://optics.ansys.com/hc/en-us/articles/360034914793-Understanding-the-Assume-Periodic-option-in-far-field-projections)也有讨论。

**如果想通过积分得到 RCWA 的复振幅，可以这样做。**

沿用我们报告中的角谱定义：

\[
A_L(q;d)=
\int_{-L/2}^{L/2}E_r(x,d)e^{-iqx}\,dx.
\]

这里 \(E_r(x,d)\) 是反射监视面上的**复电场**，\(d\) 是监视面与 RCWA 参考面的距离。选择一个包含第 \(m\) 级、且不包含相邻级中心的角带 \(B_m\)，可计算

\[
\boxed{
r_m^{\mathrm{积分}}
\;\approx\;
\frac{1}{2\pi E_i}
\int_{B_m}
A_L(q;d)e^{-i\beta(q)d}\,dq
}
\]

其中

\[
\beta(q)=\sqrt{k_0^2-q^2}.
\]

这个积分保留了角谱的**复数实部、虚部和正负相位**；\(e^{-i\beta(q)d}\) 用来把不同角度的场移回共同参考面。结构变长、该角带能很好地隔离目标级、照明与边缘误差足够小时，这个积分可以趋近 \(r_m\)。

我刚才用之前保存的 **400 周期真实 FDTD 复角谱**，对 \(+1\) 级重新做了这项积分。积分区间取相邻级之间的中点，即从零级与一级的中点到一级与二级的中点；换成角度约为 \(7.64^\circ\) 到 \(23.52^\circ\)，一级中心是 \(15.43^\circ\)。

| \(+1\) 级复振幅的获取方式 | 结果 |
|---|---:|
| RCWA 离散级 | \(0.333462-0.148843i\) |
| FDTD：对一级角带作复角谱积分 | \(0.328172-0.145728i\) |
| FDTD：取一级中心并按窗口长度归一化 | \(0.328370-0.145648i\) |

所以，你提出的**“把 FDTD 这一范围积分成一个数，与 RCWA 这个级比较”确实可以做到**。这里两种 FDTD 方法得到的复数很接近；角带积分与 RCWA 的相对复误差约为 **1.68%**。剩余差异包括 FDTD 网格、有限结构、边缘和照明等误差，周期变长并不会自动让这些误差全部消失。

有一个归一化细节很重要：上面的公式使用的是**尚未除以 \(L\)** 的 \(A_L\)。如果软件或代码已经输出

\[
a_L(q)=\frac{A_L(q)}{L E_i},
\]

那么对应的积分应乘上 \(L/(2\pi)\)：

\[
r_m^{\mathrm{积分}}
\approx
\frac{L}{2\pi}
\int_{B_m}a_L(q)e^{-i\beta(q)d}\,dq.
\]

不能直接把已归一化曲线下面的数值面积当成 \(r_m\)。

**如果你关心的是这一整束衍射光携带多少功率，则应该积分功率，而不是积分复振幅。** 对本次法向入射、空气侧 TE 的定义：

\[
\boxed{
\eta_m^{\mathrm{FDTD}}
\approx
\frac{1}{2\pi L|E_i|^2}
\int_{B_m}
\frac{\beta(q)}{k_0}
|A_L(q)|^2\,dq
}
\]

它可以与 RCWA 的该级衍射效率

\[
\eta_m^{\mathrm{RCWA}}
=
\frac{\beta_m}{k_0}|r_m|^2
\]

比较。仍以 400 周期的 \(+1\) 级为例：

| 比较方式 | 相对入射功率的效率 |
|---|---:|
| RCWA 的 \(+1\) 级 | **12.8547%** |
| FDTD：对一级完整角带积分 | **12.4380%** |
| FDTD：由一级中心复振幅推算 | **12.4392%** |
| FDTD：只积分第一主瓣 | **11.2349%** |

这里可以很直观地看到：**FDTD 的整级角带功率积分与中心复振幅推算出的整级功率几乎相同。** 它们和 RCWA 仍有差异，主要与本次 400 周期工况使用的网格等数值条件有关。

只积分第一主瓣会少掉旁瓣贡献。对理想孤立 sinc，第一主瓣包含约 **90.28% 的标量谱能量**；实际电磁功率还受到角度通量权重和相邻级重叠影响。所以积分范围必须说明清楚，不能只写“积分一级附近”而不说积分到哪里。

最后，如果你说的“影响”是指**经过物镜、孔径或成像系统后，对某个像点产生什么影响**，则更一般的做法是让整个复角谱通过系统的角度响应 \(H(q)\)，再相干叠加：

\[
E_{\mathrm{out}}(x)=
\frac{1}{2\pi}
\int H(q)A_L(q)e^{iqx}\,dq.
\]

当 FDTD 的峰足够窄、而 \(H(q)\) 在这一小段范围内变化很小时，整束光的作用就近似等于用 RCWA 的离散级 \(r_m\) 计算的作用。如果孔径边缘正好切过这个峰，或者系统在峰宽范围内变化很快，就需要保留 FDTD 的角谱范围做积分。

所以针对你的原问题：**是的，一个 RCWA 级可以和 FDTD 的一段角谱通过积分建立对应；积分复场得到复数贡献，积分带权模平方得到功率贡献。取中心值只是另一种利用周期正交性提取复系数的方法，并不意味着旁边的角谱没有物理作用。**

**如果同时要求“整条扫描曲线接近”和“零级绝对基线正确”，我推荐：固定原来的 \(T_0\) 和 leakage，只拟合一个所有 Mark 共用的非零级功率增益 \(g_{\mathrm{ac}}\)。**

本次得到的参数是

\[
\boxed{g_{\mathrm{ac}}=1.009560834}
\]

而零级参数保持

\[
T_0=0.000629728295,\qquad
L_{\mathrm{SUM}}=0.00138,\qquad
L_{\mathrm{DIFF}}=0.000431.
\]

这里的“最好”指兼顾扫描曲线、绝对基线和跨结构验证。只追求整条曲线的最小二乘误差，会得到更小的 \(T_0\)，却把零级谷底调错。

**最终推荐的公式是**

\[
\boxed{
S_{\mathrm{FDTD},\chi}^{\mathrm{fit}}(s)
=
g_{\mathrm{ac}}\,N_{\mathrm{FDTD}}(s)
+
\left[T_0+L_\chi(1-T_0)\right]p_0
}
\]

其中：

- \(N_{\mathrm{FDTD}}(s)\)：从 FDTD 的**非零级复角谱**计算的扫描贡献，已经包含 \(K_m\)、电磁通量权重和入射功率归一化。
- \(p_0=P_{0,\mathrm{raw}}/P_{\mathrm{in}}\)：挡板前完整零级光的归一化功率。
- \(g_{\mathrm{ac}}\) 乘整个非零级贡献，包括它自身的周期平均值；零级项按后面的独立公式计算。

代入本次参数，可以直接写成

\[
\boxed{
S_{\mathrm{SUM}}(s)
=
1.009560834\,N_{\mathrm{FDTD}}(s)
+
0.002008859270\,p_0
}
\]

\[
\boxed{
S_{\mathrm{DIFF}}(s)
=
1.009560834\,N_{\mathrm{FDTD}}(s)
+
0.001060456882\,p_0
}
\]

这里 DIFF 沿用你提供文档中同一干涉核、替换 leakage 的比较方式。

\(N_{\mathrm{FDTD}}\) 的完整角谱公式如下。先用空场源模板估计完整零级场 \(A_0(k)\)，再令

\[
A_n(k)=A(k)-A_0(k).
\]

按照你指定的 B 方法，第 \(m\) 个角谱带整体使用相位 \(e^{-imGs}\)，其中 \(G=2\pi/p\)。于是

\[
\boxed{
N_{\mathrm{FDTD}}(s)
=
\sum_{m=1}^{18}\frac{K_m}{\gamma_m}
\int_{B_m^+}
\frac{\gamma(k)}{4\pi Z_0P_{\mathrm{in}}}
\left|
A_n(k)e^{-imGs}
-
A_n(-k)e^{+imGs}
\right|^2\,dk
}
\]

这里

\[
\gamma(k)=\sqrt{1-(k/k_0)^2},
\qquad
\gamma_m=\sqrt{1-(m\lambda/p)^2},
\]

\[
B_m^+
=
\left[(m-\tfrac12)G,(m+\tfrac12)G\right]
\cap[0,\mathrm{NA}\,k_0].
\]

完整零级功率则为

\[
\boxed{
p_0=
\int_{|k|\le \mathrm{NA}k_0}
\frac{\gamma(k)}{4\pi Z_0P_{\mathrm{in}}}
|A_0(k)|^2\,dk
}
\]

这些都是角谱积分。\(K_m/\gamma_m\) 是针对**原始、尚未加入仪器权重的电场角谱**所需的转换：连续积分已经含有电磁通量因子 \(\gamma(k)\)，再用固定的 \(K_m/\gamma_m\) 对应 D4C 的 \(K_m|r_m|^2\) 定义。

在这套推荐实现中，零级由标量项处理一次，因此不再额外加同一份 \(P_{0,\mathrm{pass}}\)。对于本次对称结构，

\[
N_{\mathrm{FDTD}}(0)\simeq0,
\]

所以谷底为

\[
\boxed{
S_\chi(0)=
[T_0+L_\chi(1-T_0)]p_0>0.
}
\]

这也保证了拟合非零级增益时，不会把零级漏光底一起缩放。

如果你要自己重新拟合 \(g_{\mathrm{ac}}\)，它只有一个未知量，甚至可以直接求解。令

\[
y_j(s)=S_{\mathrm{D4C},j}(s),\qquad
z_j=[T_0+L_{\chi_j}(1-T_0)]p_{0,j},
\]

则拟合目标为

\[
\min_g
\sum_j w_j\sum_s
\left[gN_j(s)+z_j-y_j(s)\right]^2,
\]

其解是

\[
\boxed{
g^*=
\frac{
\displaystyle\sum_j w_j\sum_s
N_j(s)\,[y_j(s)-z_j]
}{
\displaystyle\sum_j w_j\sum_sN_j(s)^2
}
}
\]

本次用

\[
w_j=\frac{1}{\sum_s y_j(s)^2}
\]

平衡不同强度的训练曲线；所有训练 Mark 和两种 leakage 版本共用同一个 \(g\)，然后冻结它预测留出结构。

关键就在于：**零级对应一个完整的展宽分量，不能只用 \(k=0\) 那个采样点代表它。**

下面按拿到 FDTD 角谱之后的实际处理顺序说明。

**1. 从总反射角谱 \(A(k)\) 中提取零级分量 \(A_0(k)\)。**

先写成：

\[
A(k)=A_0(k)+A_{\mathrm n}(k),
\]

其中 \(A_{\mathrm n}\) 是后续用于计算非零级扫描信号的角谱。

有限光斑下，零级有一定宽度和尾部。我们采用的提取方法是：

- 从空场 FDTD 得到实际入射光的复角谱模板。
- 按各衍射级的位置 \(k_m=mG\)，其中 \(G=2\pi/\Lambda\)，构造各阶的移位模板，并统一参考面。
- 对总反射角谱做**复数联合拟合**，得到零级以及其他阶的分量。

我们实际使用的模板拟合还允许每阶的反射响应随入射角有二次变化，因此比“所有衍射峰都严格保持同一种高斯形状”更灵活。

**这里拟合的是 FDTD 的复场角谱，没有使用 RCWA 扫描曲线来决定零级大小。** 不同 Mark 提取出不同的零级功率，是结构反射响应不同的结果。

这一处理也避免了一个问题：如果仅按“离 \(k=0\) 最近的区间”定义零级，落到区间外的零级尾部，就可能被错误地赋予一级或其他级的扫描相位。

**2. 对完整的 \(A_0(k)\) 做功率积分，得到归一化零级功率 \(p_0\)。**

\[
\boxed{

\frac{1}{4\pi Z_0P_{\mathrm{in}}}
\int_{|k|\leq \mathrm{NA}k_0}
\gamma(k)\,|A_0(k)|^2\,dk
}
\]

其中

\[
\gamma(k)=\sqrt{1-\left(\frac{k}{k_0}\right)^2},
\qquad k_0=\frac{2\pi}{\lambda}.
\]

这里积分的是**收集 NA 内的整个零级分量**，包括它的尾部。

因此，对零级而言，我们需要积分的量是：

\[
\boxed{\text{零级功率}\ \propto\int \gamma(k)|A_0(k)|^2\,dk}
\]

这个积分得到的是功率；若要提取与 RCWA 对应的零级**复振幅**，则要用前面的复场模板投影系数，二者是不同的量。

\underbrace{T_0p_0}_{\text{透过的零级功率}}

\[

}

}

这里的 \(w_{\mathrm b}\) 是半径。Lumerical 的 Gaussian 源也采用“场降至 \(1/e\)、强度降至 \(1/e^2\)”的半径定义，核对尺寸时要保持一致。[Ansys 的 Gaussian 源参数定义](https://optics.ansys.com/hc/en-us/articles/360034382854-Plane-wave-and-beam-source-Simulation-object)

\[
T_{\mathrm{eff}}
=
\operatorname{erfc}
\left(\frac{\sqrt2\,D_{\mathrm{stop}}}{D_{\mathrm b}}\right).
\]

你的原公式是

\[
T_0=
\operatorname{erfc}
\left(
\frac{\sqrt2\times500\,\mu\mathrm m}
{0.778\times376\,\mu\mathrm m}
\right).
\]

因此，一种完全自洽的解释是：

| 参数 | 数值 | 目前依据 |
|---|---:|---|

**边缘怎么处理：当前应先采用硬边，不额外拟合一个软边。**

最简单的挡板模型可以写成

\[
H_{\mathrm b}(X)=
\begin{cases}
0,& |X-X_c|<250\,\mu\mathrm m,\\
1,& |X-X_c|>250\,\mu\mathrm m.
\end{cases}
\]

其中先取居中 \(X_c=0\)。换到角谱中，就是

\[
\boxed{
H(k)=
\begin{cases}
0,& |k|<h,\\
1,& |k|>h.
\end{cases}
}
\]

如果以后知道挡板材料存在局部功率透射率 \(\tau\)，内部的**场透过系数**才改为 \(\sqrt{\tau}e^{i\phi}\)。这里的 \(\tau\) 是挡板材料内部的透射率，和整束光的残余比例 \(T_0\) 不是同一个量。

我们程序对离散边缘采用的是**积分单元与挡板的交叠比例**：挡板边界落在两个 \(k\) 采样点之间时，按实际被遮挡的比例积分，避免挡板宽度稍微改变，结果就突然跳一个采样格。**这属于数值积分处理，并不代表实际挡板有渐变透过率。**

在薄屏标量模型内，硬边产生的衍射由遮挡后的场传播体现，不需要再额外人为加一个 sinc 或平滑函数。只有实际边缘形貌、厚度、位置误差等提供了依据，才应增加相应的边缘模型。

**为什么真实尺寸固定了，仍然可能与 D4C 对不上？**

最需要区分的是下面几件事：

- **同一个 \(250\,\mu\mathrm m\) 挡板，挡住多少光，取决于挡板处的光斑尺寸。** 仅有半宽还不能确定透过率。当前残余只有 \(10^{-4}\) 到 \(10^{-3}\) 量级，计算非常依赖高斯尾部；在上述工作点，一阶估计中，挡板半宽与光束半径之比改变 \(1\%\)，透过比例就会改变约 \(12.6\%\)。
- **条形挡板和圆形挡板对应不同的积分。** 我们目前采用的是一维条形挡板的 erfc 公式。如果实物是圆形中心遮挡，就需要二维角谱；对圆对称理想高斯，同半径圆挡的残余是 \(\exp(-2a^2/w_{\mathrm b}^2)\)。二维与三维高斯的功率积分本身就有区别。[COMSOL 对二维、三维高斯功率积分的说明](https://doc.comsol.com/6.3/doc/com.comsol.help.roptics/roptics_ug_optics.6.62.html)
- **真实挡板作用于该位置上的全部场。** 零级尾部、其他衍射级的尾部，只要落在同一个位置，都会被同一个 \(H\) 遮挡。它不会识别某个场来自哪个衍射级。
- **挡板后的零级功率，不自动等于某个探测端口的背景。** 后面的分束、干涉和检测方式仍会影响读出。上一条回答中的
  \[
  p_{0,\mathrm{pass}}+L_\chi(p_0-p_{0,\mathrm{pass}})

这个关系体现了高斯束腰尺寸与角宽度的反比关系。[高斯光束半径及束腰—发散角关系](https://www.edmundoptics.com/knowledge-center/application-notes/lasers/gaussian-beam-propagation/)

所以三个量应当这样区分：

| 位置或表示方式 | 横坐标 | 本次对应的宽度 |
|---|---|---|
| Mark 表面的入射场 | 实空间 \(x\) | 半径 \(19\,\mu\mathrm m\)，直径 \(38\,\mu\mathrm m\) |
| 傅里叶变换后的角谱 | 横向波数 \(k\) | 理想强度 \(1/e^2\) 半宽 \(0.105263\,\mathrm{rad}/\mu\mathrm m\) |
| 挡板所在傅里叶平面 | 实空间 \(X\) | 取决于 \(f_{\mathrm{eff}}\)；当前等效解释给出半径 \(146.264\,\mu\mathrm m\) |

**但仅凭 38 μm，确实不能唯一算出 \(146.264\,\mu\mathrm m\)。**

我们还需要光学系统的尺度。前面使用的那组等效值满足

\[
w_0=19\,\mu\mathrm m,\qquad
f_{\mathrm{eff}}\approx16.4108\,\mathrm{mm}
\]

从而

\[
w_{\mathrm b}\approx146.264\,\mu\mathrm m.
\]

由于实际 \(f_{\mathrm{eff}}\) 尚不知道，这说明它们**数学上相容**，还不能证明真实挡板处的光斑就是这个大小。

**一级光的公式为什么也用了 \(w_{\mathrm b}\)？**

那一步采用了一个明确的近似：**各衍射级是同一个入射高斯角谱的移位副本。**

如果第 \(m\) 阶反射系数在入射角谱范围内变化很小，就有

\[
\boxed{
A_m(k)\approx r_m(0)\,F(k-mG).
}
\]

代入高斯入射角谱：

\[
A_m(k)\propto
r_m(0)
\exp\!\left[-\frac{w_0^2(k-mG)^2}{4}\right].
\]

这时，各阶的中心位置不同，但包络宽度相同。映射到挡板平面后，就是

\[
I_m(X)\propto
|r_m(0)|^2
\exp\!\left[-\frac{2(X-X_m)^2}{w_{\mathrm b}^2}\right].
\]

**一级公式中沿用 \(w_{\mathrm b}\)，来自“同一高斯包络平移”的近似，并不是重新给一级设置了一个光源。**

实际有限 Mark 的 FDTD 角谱可以偏离这个近似：反射响应随入射角变化、有限结构散射等，都会改变各阶的形状。因此，上一条的“一级损失约 \(0.00264\%\)”应理解为这组等效光路下的**理想移位高斯估算**，不是已经从每个 Mark 的真实 FDTD 一级分量中测得的结果。

**在实际 FDTD 数据处理中，不需要再给一级指定 \(w_{\mathrm b}\)。** 正确流程是：

\[
\boxed{
38\,\mu\mathrm m\text{ 高斯入射}
\;\longrightarrow\;
\text{FDTD 得到实际 }A(k)
\;\longrightarrow\;
H(k)A(k)
\;\longrightarrow\;
\text{扫描信号积分}.
}
\]

\(A(k)\) 已经包含了 38 μm 入射光斑产生的展宽。后处理中只施加挡板的传递函数，**不要再乘一个用 \(w_{\mathrm b}\) 构造的高斯包络**。\(w_{\mathrm b}\) 在前面的解析估算中用于解释尺寸和尾部；真实 FDTD 的峰宽及尾部应直接由计算得到的复角谱决定。

**这是一个关键问题，但最敏感的一步是：在给非零级角谱加扫描相位之前，先在复场层面减掉完整的 \(A_0(k)\)。仅仅把 \(p_0\) 的功率积分做完整，还不能消除留在其他角带中的零级尾部。**

如果只去掉 B 方法规定的中央角带，**确实会留下零级尾部，并可能产生多余的扫描信号；但包含其他衍射级后，整条曲线不保证在所有位移处都偏大。**

我把这两个影响分开说明。

**1. 只去掉中央角带，会留下什么？**

本次 B 方法把零级中央角带定义为

\[
B_0:\quad |k|<\frac G2,
\qquad G=\frac{2\pi}{\Lambda}.
\]

对 \(\Lambda=16\,\mu\mathrm m\)：

\[
\frac G2=0.1963495\,\mathrm{rad}/\mu\mathrm m.
\]

但零级的完整分量 \(A_0(k)\) 在这个范围外仍有尾部。因此，“去掉中央角带”与“去掉完整零级”是两种操作：

\[
\begin{aligned}
\text{去掉中央角带：}\quad&
A_{\mathrm{cut}}(k)
=[1-\chi_{B_0}(k)]A(k),\\[3pt]
\text{去掉完整零级：}\quad&
A_{\mathrm n}(k)=A(k)-A_0(k).
\end{aligned}
\]

第一种操作会把中央范围内的场全部删掉，同时保留中央范围之外的零级尾部。

这些尾部进入一级角带后，B 方法会按照“一级”给它们施加位移相位。**本来属于零级、应该保持零级位移相位的场，就被错误地赋予了一级扫描相位。**

例如，对称零级尾部满足 \(A_0(k)=A_0(-k)\)。如果它被当成一级处理，就会出现

\[
\left|
A_0(k)e^{-iGs}-A_0(-k)e^{+iGs}
\right|^2
=
2|A_0(k)|^2[1-\cos(2Gs)].
\]

**这就是虚假的扫描起伏。即使输入场中根本没有一级光，也能被这种分带处理算出“一级扫描信号”。**

**2. 零级尾部很小，为什么仍然值得关注？**

对本次 \(w_0=19\,\mu\mathrm m\) 的理想高斯，中央角带外的零级功率比例约为

\[
\epsilon_0
=
\operatorname{erfc}
\left(\frac{w_0G}{2\sqrt2}\right)
\approx1.90993\times10^{-4}.
\]

也就是零级总功率的

\[
\boxed{0.01910\%.}
\]

这个比例很小，但 D4C 中真正保留下来的零级漏光背景，本来就只有约

\[
Z_{\mathrm{SUM}}\approx0.00200886\,p_0.
\]

留下的尾部若按非零级扫描项处理，就没有再受这个很小的零级背景系数约束，因此相对于漏光背景，影响可以明显放大。

我们已有一个**只输入零级分量的合成控制**：中央角带法产生了约

\[
5.802\times10^{-5}
\]

的虚假扫描峰谷差，约相当于该例 SUM 零级背景的 **9.5%**；减掉完整零级分量后，这个虚假扫描项为零。这是用于隔离算法问题的合成控制，不是实际 Mark FDTD 的新测量。[仅含零级的控制数据](D:/工作/AH53_D4C_ZeroOrder_20261105/analysis/synthetic_control/zero_only_spurious_harmonics.csv)

**3. 所以最终结果一定偏大吗？需要区分两种情况。**

如果只有零级尾部被错误保留下来，它产生的虚假强度项是非负的，会多算信号。

如果同时存在真实非零级场，B 公式中的差场可以写成

\[
D_{\mathrm{total}}(s)
=
D_{\mathrm n}(s)+D_{\mathrm{tail}}(s).
\]

那么强度差包含

\[
\boxed{
|D_{\mathrm{total}}|^2-|D_{\mathrm n}|^2
=
|D_{\mathrm{tail}}|^2
+
2\operatorname{Re}
\left[D_{\mathrm n}D_{\mathrm{tail}}^*\right].
}
\]

第一项始终非负，第二项是相干交叉项，可以为正，也可以为负。因此，实际曲线可能在一些位置偏高、另一些位置偏低，也可能改变谐波比例。

另外，若你用中央角带估计零级功率：

\[
p_{0,\mathrm{band}}
=
\int_{B_0}W(k)|A(k)|^2\,dk,
\]

它既漏掉了零级尾部，也可能包含其他级的尾部及交叉项，不能保证它与完整 \(p_0\) 之间有固定的大小关系。**如果只有孤立零级、没有其他级混入，那么只积分中央角带得到的零级功率反而会偏小。**

**4. 我们的真实 FDTD 数据也说明，不能笼统说“整个结果都偏大”。**

\[
\boxed{
\begin{aligned}
&\text{先估计完整零级复场 }A_0(k),\\
&\text{在复场层面相减： }A_{\mathrm n}(k)=A(k)-A_0(k),\\
&\text{用 }A_{\mathrm n}(k)\text{ 做非零级 B 方法积分},\\
&\text{单独积分完整 }|A_0(k)|^2\text{ 得到 }p_0,\\
&\text{最后只加一次 }[T_0+L_\chi(1-T_0)]p_0.
\end{aligned}

有。**你要找的核心文件是 [`analysis/zero_order_models.py`](D:/工作/AH53_D4C_ZeroOrder_20261105/analysis/zero_order_models.py:161)**，其中两个函数实现了我们推荐的流程：

- **`b_features()`**：从总复角谱中减去完整零级分量 \(A_0(k)\)，对剩余角谱计算 B 方法的积分，同时对完整零级做功率积分，得到 \(p_0\)。
- **`candidate_scan(..., model="scalar_zero_once")`**：生成扫描曲线，并加回一次
  \[
  [T_0+L_\chi(1-T_0)]p_0.
  \]
  包含你规定的 \(T_0p_0\) 和漏光项。

[GitHub 上的这个 Python 文件](https://github.com/ychen1213/si532-rcwa-fdtd-angular-spectrum/blob/main/D4C_532nm_Gaussian38/analysis/zero_order_models.py)

**最关键的调用方式如下：**

```python
# d 是已经保存的 FDTD 角谱数据
# A_zero_degree2_V 是由源模板联合复数拟合得到的完整零级估计

f = b_features(
    d["kx_rad_m"],
    d["A_ref_V"],
    float(d["Pin_W_m"]),
    selected_orders=np.arange(1, 19),
    NA=0.6,
    stop_halfwidth_rad_um=0.0,
    A_zero_ref_V=d["A_zero_degree2_V"],
)

S_sum = candidate_scan(
    f,
    s_um,
    model="scalar_zero_once",
    channel="SUM",
    convention="K_over_gamma",
    gain=1.0,
)
```

这里有两个参数必须注意：

1. **必须传入 `A_zero_ref_V`。** 这样才执行完整复场相减 \(A-A_0\)；如果不传，程序会退回“中央零级角带”的定义。
2. **`stop_halfwidth_rad_um=0.0`。** 这条推荐分支采用完整零级相减，再按标量 \(T_0\) 加回零级背景，不额外施加实际挡板。

**如果要直接运行现有项目，入口是 [`analysis/run_analysis.py`](D:/工作/AH53_D4C_ZeroOrder_20261105/analysis/run_analysis.py:74)。** 它会比较多种处理方式，你要看的分支名称是：

```text
weighted_nostop_mode2_scalar
```

其含义就是：**使用完整零级估计、无额外挡板、采用 \(K_m/\gamma_m\) 权重、零级标量项只加一次。**

在项目目录中运行：

```powershell
python analysis/run_analysis.py --suffix _fine
```

结果保存在 [outputs/comparison_fine](D:/工作/AH53_D4C_ZeroOrder_20261105/outputs/comparison_fine)。

如果手上还只有原始监视面复场，需要先运行 [`analysis/prepare_spectra.py`](D:/工作/AH53_D4C_ZeroOrder_20261105/analysis/prepare_spectra.py:47)，它负责生成角谱以及 `A_zero_degree2_V`。现有项目已经保存了这些数据，可以直接使用。

另外，**上面示例取 `gain=1.0`，不做拟合校正。** `candidate_scan()` 的 `gain` 会缩放整条信号；若要使用此前仅作用于非零级的 \(g_{\mathrm{ac}}\)，应单独计算为

```python
N = scan_from_features(f, s_um, convention="K_over_gamma")

S_sum = (
    1.009560834371314 * N
    + zero_coefficient("SUM") * f.zero_raw_power
)
```
